# PRESCOT 3D

Podgląd modeli taśm LED: PREMIUM, DELUX, COB, WCOB i COB IP67.

Strona: https://bohunek5.github.io/3d/

Modele można obracać i przełączać między wariantami światła. Do pobrania są rendery PNG, modele GLB i edytowalne sceny Blender.

WCOB ma wypukłą mleczną osłonę; WCOB i IP67 są bez logo na osłonach. Modele są rekonstrukcjami na podstawie materiałów referencyjnych, nie fabrycznym CAD.

Statyczna strona działa na GitHub Pages z gałęzi `main`, katalog główny. Modele GLB są pobierane po włączeniu podglądu 3D.
